# 老人防摔监护系统

基于传感器姿态采集的老人跌倒检测与告警系统，2026 年中国国际大学生创新创业大赛**市赛获奖**项目。

## 我负责的部分
- 传感器与主控电路搭建、接线与供电调试
- 姿态数据采集与跌倒判定逻辑、告警程序编写
- 整机联调与现场演示

## 工作方式
1. 传感器持续采集老人姿态数据（加速度/角度变化）
2. 主控实时判定是否发生跌倒
3. 判定为跌倒立即触发告警
