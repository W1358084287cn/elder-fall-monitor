## 1. 产品概述

### 1.1 产品功能

老人防摔智能报警系统是一款专为老年人设计的智能安全设备，具备以下核心功能：

- **毫米波雷达摔倒检测**：通过SFD01毫米波雷达实时监测人体姿态变化
- **加速度异常检测**：ADXL345加速度传感器辅助检测跌倒和剧烈运动
- **心率血氧监测**：MAX30102传感器实时监测生命体征
- **自动SOS报警**：检测到摔倒后自动拨打预设号码
- **GPS定位**：内置GPS模块，支持位置追踪
- **多重报警方式**：声、光、震动同步报警

### 1.2 适用人群

- 独居老人
- 行动不便的老年人
- 需要24小时监护的高风险人群

## 3. 快速开始

### 3.1 首次使用步骤

1. **连接电源**
   - 使用USB-C数据线连接电源
   - 或安装3.7V锂电池

2. **等待启动**
   - 设备会自动启动
   - 显示开机Logo和版本信息
   - 约10秒后进入主界面

3. **配置WiFi**
   - 若未配置WiFi，屏幕显示配网提示
   - 手机连接热点 `FallAlarm-Config`
   - 浏览器访问 `192.168.4.1`
   - 选择并连接可用的WiFi网络
   - 输入WiFi密码，点击保存

4. **测试功能**
   - 按住触摸区域3秒以上模拟摔倒
   - 确认10秒倒计时后是否正常报警

### 3.2 指示灯说明

| 状态 | 指示灯 | 说明 |
|------|--------|------|
| 待机 | 绿色闪烁 | 正常运行 |
| 报警中 | 红色快闪 | SOS报警进行中 |
| 取消 | 黄色闪2次 | 报警已取消 |
| 配置模式 | 黄色常亮 | 等待配网 |

## 4. 功能说明

### 4.1 摔倒检测

**检测方式**：
- 毫米波雷达检测人体姿态变化
- 加速度传感器检测异常运动
- 两者结合判断是否为摔倒事件

**检测灵敏度**：
- 默认检测延迟：0.5秒
- 摔倒判定后启动10秒倒计时
- 用户可在倒计时内取消报警

### 4.2 SOS报警流程

```
检测到摔倒
    ↓
启动10秒倒计时
    ↓
┌─────────────────────┐
│ 倒计时期间可取消报警  │
│ (双击触摸区域)       │
└─────────────────────┘
    ↓ (倒计时结束)
触发4G电话报警
    ↓
启动SOS蜂鸣+震动
    ↓ (30秒后)
自动停止报警
```

### 4.3 报警方式

| 方式 | 说明 |
|------|------|
| 4G电话 | 自动拨打预设号码 |
| 蜂鸣器 | SOS节奏(1秒响2次) |
| LED灯 | 红色闪烁 |
| 震动马达 | 与蜂鸣器同步 |

### 4.4 语音命令

| 命令 | 功能 |
|------|------|
| "救命" / "SOS" | 立即触发报警 |
| "取消" / "撤警" | 取消当前报警 |

## 5. 操作指南

### 5.1 正常佩戴

1. 佩戴设备于胸前或腰部
2. 确保雷达朝向人体前方
3. 设备会自动监测并显示状态

### 5.2 报警取消

在10秒倒计时期间：
- **双击触摸区域**即可取消报警
- 或说出"取消"/"撤警"语音命令

### 5.3 WiFi重新配置

1. 长按触摸区域5秒以上
2. 设备进入配置模式
3. 按首次配置步骤重新设置WiFi

### 5.4 状态查看

主界面显示：
- 心率 (BPM)
- 血氧 (%)
- GPS状态
- WiFi连接状态
- 当前时间

## 6. 常见问题

### Q1: 设备无法开机？
**解决方案**：
- 检查电池电量或USB连接
- 按复位键重启
- 若仍无法开机，联系售后服务

### Q2: 摔倒检测不灵敏？
**解决方案**：
- 确保雷达前方无遮挡
- 避免剧烈运动时触发误报
- 检查传感器连接线

### Q3: 4G电话未触发？
**解决方案**：
- 检查4G模块连接
- 确认SIM卡正常
- 查看串口日志排查问题

### Q4: WiFi连接失败？
**解决方案**：
- 确认WiFi密码正确
- 检查路由器是否正常
- 重启设备后重试

### Q5: 误报警较多？
**解决方案**：
- 避免剧烈运动
- 等待设备稳定后再活动
- 摔倒后立即双击取消

## 7. 安全注意事项

### 7.1 使用安全

- 请勿在洗澡时佩戴
- 避免接触水源
- 远离强磁场环境

### 7.2 电池安全

- 使用标准USB-C数据线充电
- 勿使用非标充电器
- 电池鼓胀时立即停止使用

### 7.3 维护保养

- 定期清洁设备表面
- 避免高温存放
- 长期不使用时请取出电池
